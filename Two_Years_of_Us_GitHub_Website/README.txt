ANNIVERSARY WEBSITE

Quiz answers are configured: Q1 C (Crab stew), Q2 B (Ikkakumon), Q3 D (All of the above).
1. Add 12 JPG photos named photo01.jpg through photo12.jpg to photos/.
2. Add an MP3 named our-song.mp3 to music/. Use music you have the right to publish.
3. Upload index.html plus the photos and music folders to a public GitHub repository.
4. In repository Settings > Pages, choose Deploy from a branch, main, /(root), Save.
5. Wait for the published link shown on the Pages settings page.

Note: The quiz is a playful gate, not secure password protection. Public GitHub Pages files can be viewed by others.
